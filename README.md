# TemanCipta — HRIS

Website demo HRIS berbasis HTML, CSS, dan JavaScript dengan tampilan responsif, tema 3D, dan animasi.

**Fitur:** dashboard, data karyawan, absensi, pengajuan cuti, dan ringkasan payroll.

**Menjalankan:** buka `index.html` di browser atau melalui Live Server di VS Code.

**Catatan:** menggunakan data contoh, belum terhubung database. Perubahan data akan direset saat halaman dimuat ulang.
